# Runtime packages baked into the Gershwin-on-NextBSD live ISO. NextBSD packages
# only, installed from the NextBSD repository (`pkg install -r NextBSD`); the
# build configures no FreeBSD repository. These are runtime prerequisites
# Gershwin needs but its build (bootstrap.sh, checkout.sh, make install) does
# not install itself: gershwin-developer's Library/OSSupport/nextbsd.txt brings
# the X client libraries, Mesa, gnustep-support, printing-support and the
# toolchain (with git), but no X server.
#
# pkg resolves each package's full dependency closure automatically. One package
# per line; blank lines and #-comments are ignored.

# The X server, in /usr/X11 (X -> Xorg, setuid): XLibre 25.1.9 with the
# modesetting, scfb and vesa video drivers and the evdev, libinput, kbd, mouse,
# synaptics, joystick and vmmouse input drivers, plus the X tools Gershwin's
# panes run: xset (Energy), setxkbmap and xkbcomp (Keyboard, LoginWindow),
# xinput (Mouse) and xrandr. Pulls in displayserver-support, xlibs, mesa and
# mesa-x11. vesa and vmmouse are amd64 only.
